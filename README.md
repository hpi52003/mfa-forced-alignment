# Forced Alignment with the Montreal Forced Aligner (MFA)

Aligns six utterances to their transcripts at word and phone level and exports Praat TextGrids.
Data: three radio-news clips (`F2BJRLP1-3`) and three learner-English minimal-pair clips
(`ISLE_SESS0131_BLOCKD02_01-03`).

## Repository layout
```
raw_data/               original audio and transcripts, as provided
corpus/                 MFA-ready data (generated by scripts/prepare_corpus.py)
scripts/
  prepare_corpus.py     converts audio and cleans transcripts
  build_dictionary.py   stock dictionary + G2P output + manual overrides
  run_pipeline.bat      full pipeline for Windows
  run_pipeline.sh       full pipeline for Linux/macOS
  check_setup.py        one-minute self-check (tools, files, dictionary build)
manual_overrides.dict   hand-written pronunciation for "wbur"
custom_oov.dict         G2P output for words missing from the stock dictionary
custom_dictionary.dict  final dictionary used for alignment
output/custom_dict/     TextGrids: english_us_arpa model + custom dictionary (+ alignment_analysis.csv)
output/english_mfa/     TextGrids: english_mfa model and dictionary (+ alignment_analysis.csv)
report/                 report (docx and pdf) and the four Praat screenshots
```

## Environment (Windows 11, tested)
MFA cannot be installed with pip alone. Install Miniforge, open the Miniforge Prompt, then:
```
conda create -n aligner -c conda-forge python=3.11 montreal-forced-aligner ffmpeg -y
conda activate aligner
mfa version        # 3.4.4
ffmpeg -version    # 8.1.2
```

## Quick check (about one minute)
Confirms that mfa and ffmpeg work, the files are in place, data preparation runs, and the dictionary
builder reproduces `custom_dictionary.dict`. It does not run any alignment.
```
python scripts\check_setup.py
```

## Run everything
From the project folder, inside the `aligner` environment:
```
scripts\run_pipeline.bat          (Windows)
bash scripts/run_pipeline.sh      (Linux/macOS)
```

## What each step does
1. **Models.** `mfa model download` for the `english_us_arpa` acoustic model, dictionary and G2P model,
   and for the `english_mfa` acoustic model and dictionary.
2. **Data preparation.** The three `F2BJRLP*.wav` files are NIST SPHERE files with a .wav extension;
   they are converted with ffmpeg to 16 kHz mono 16-bit PCM WAV. Transcripts are lower-cased, stripped of
   punctuation and line breaks, and split words are repaired.
3. **Validation.** `mfa validate corpus english_us_arpa english_us_arpa --clean` reported no audio or
   transcript problems and 22 out-of-vocabulary word types. It takes about 13 minutes because MFA also
   trains a monophone model.
4. **G2P.** `mfa g2p corpus english_us_arpa custom_oov.dict --dictionary_path english_us_arpa` produced
   pronunciations for dukakis, melnicove, maffy, depoliticize and wbur.
5. **Custom dictionary.** `build_dictionary.py` appends the G2P output to the stock dictionary. The G2P
   pronunciations for "wbur" were wrong (it is spelled letter by letter), so they are replaced by the
   hand-written entry in `manual_overrides.dict`.
6. **Alignment.** `mfa align corpus custom_dictionary.dict english_us_arpa output\custom_dict --clean --single_speaker`
7. **Comparison.** The same corpus aligned with the `english_mfa` model and dictionary.

## Viewing results
Open `corpus/<name>.wav` and the matching `.TextGrid` in Praat (https://www.praat.org), select both
objects and choose View & Edit. For long files, use Time > Zoom to show 10 seconds or less so the
spectrogram is drawn.

## Notes
- The first run was done step by step by hand; the pipeline scripts chain exactly those commands.
- `scripts\run_pipeline.bat` was later run from start to finish on Windows 11 (in a copy of the project) and
  completed without errors; `python scripts\check_setup.py` then passed all eight checks.
- `scripts/run_pipeline.sh` (Linux/macOS) contains the same commands but has not been run.
- Forced alignment assumes the transcript is correct, so it cannot detect mispronounced words.
